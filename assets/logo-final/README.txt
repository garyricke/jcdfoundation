JCD FOUNDATION — LOGO PACKAGE
=============================
Approved mark: "Tamed Original" (final, 2026).

WHICH FILE DO I USE?
--------------------
Web & general use (scalable):
  jcd-logo-primary.svg    Navy mark — for light backgrounds
  jcd-logo-reversed.svg   White mark — for navy / dark backgrounds

Office, email, slides (raster, transparent):
  jcd-logo-primary.png    Navy mark, 1600px wide
  jcd-logo-reversed.png   White mark, 1600px wide

Print / vendors (vector PDF):
  jcd-logo-primary.pdf    Navy mark
  jcd-logo-reversed.pdf   White mark

Favicon / app icon / social avatar:
  jcd-favicon.svg         Square mark (scalable)
  jcd-favicon-512.png     512px
  jcd-favicon-180.png     180px (Apple touch icon)
  jcd-favicon-32.png      32px (browser tab)
  jcd-favicon.pdf         Square mark (vector)

RULES
-----
- Never reproduce below 40px height (digital) or 0.5in (print).
- Keep clear space equal to the height of the "J" on all sides.
- Do not rotate, stretch, recolor, add shadows, or apply gradients.
- Use only these approved files.

Questions: contact the JCD Foundation marketing team.
