JCD Foundation Domain Setup Guide
Step-by-step · no experience needed

Point the website live.

This guide walks you through one task: telling the internet that thejcdfoundation.org should show the new JCD Foundation website. You'll add two small settings at the company where the web address is registered. Follow the steps in order — you can't break anything as long as you only add the two records below.

About 10 minutes of work · then up to a day for the internet to catch up

What you're doing, in one sentence

A web address (like thejcdfoundation.org) and a website are two separate things. Right now the address isn't connected to anything. You're going to connect it to the new site, which lives on a service called Netlify.

Before you start — have these ready

1. The login for wherever thejcdfoundation.org was purchased (the "registrar" — e.g. GoDaddy, Namecheap, Squarespace, Network Solutions).

2. The two values below — both are already filled in for you. (If anything ever looks blank, ask Gary.)

Here are the two records you'll add. Don't worry about what they mean — just copy them exactly. Most registrars call this screen "DNS," "Manage DNS," or "DNS Records."

The one rule: only ADD, never delete

Leave every other record exactly as it is — especially anything labeled MX or TXT. Those run the foundation's email (Bob.Vaughan@TheJCDFoundation.org). You're only adding the two records above.

If a record of Type "A" with Name "@" already exists, don't add a second one — just edit the existing one so its value reads 75.2.60.5.

The steps

  1. Sign in to the registrar

    Go to the website where thejcdfoundation.org was purchased and log in.

  2. Find the domain's DNS settings

    Look for thejcdfoundation.org in your account, then open the page called DNS, Manage DNS, or DNS Records. (Often under a "Manage" or gear/settings button next to the domain.)

  3. Add Record 1 (the "A" record)

    Click Add record. Choose type A, set the name/host to @, and paste 75.2.60.5 as the value. Save it.

  4. Add Record 2 (the "CNAME" record)

    Click Add record again. Choose type CNAME, set the name/host to www, and paste thejcdfoundation.netlify.app as the value. Save it.

  5. Double-check email is untouched

    Glance at the list of records. Anything marked MX should still be there, unchanged. If so, you're good.

  6. Save / confirm, then wait

    Make sure both new records are saved. Now the internet needs time to update — usually a few minutes, sometimes up to 24 hours. This is normal.

How you'll know it worked

  • Open a browser and type thejcdfoundation.org — the new JCD site appears.
  • In the Netlify dashboard, the domain shows a green check / "Netlify DNS verified."
  • If it's not live yet, wait a bit longer — DNS changes can take the rest of the day.

One alternative (only if Netlify asks for it)

Some setups instead ask you to change the domain's "nameservers" to Netlify's. That's also fine, but it moves everything — including email — over to Netlify, so the email records would have to be rebuilt. Unless Gary tells you to use nameservers, stick with the two records above — they're the safe choice that leaves email alone.
